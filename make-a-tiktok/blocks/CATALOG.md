# Generic building blocks

Shared by every studio. `*` marks signature blocks: reuse freely, but not in consecutive videos.
Regenerated by `studio.mjs`; edit block.json files, not this table.

| Block | Kind | Version | Summary |
| --- | --- | --- | --- |
| answer-card | component | v2 | A result card (eyebrow, badge, avatar initials, name, meta, gains, primary and secondary buttons) that opens with a circular reveal from a point, rows cascade in, an AI answer streams word by word with tags, then a tap presses the primary button, which wipes to a confirmed state with sparks. |
| arrangement-build-drop | sound | v1 | Music bed for soundtrack.mjs: pads opening through a build, tuned 808 per bar, light drums before the drop and any genre pattern after it (per-bar 'four' for montage bars), snare roll and riser into a near-silent gap, the drop, and a ringing final chord. Places kicks from the shared KICKS list. |
| chat-thread | component | v2 | AI assistant chat card: branded header, empty state with suggestion chips, question typed into the composer with a caret, send press, message lifts into the thread, thinking row with the dotted orb and shimmer text. |
| dot-field-scan * | overlay | v2 | World overlay that visualizes filtering many options to one: dots pop onto the floor, scan rings expand from an origin and eliminate dots pass by pass, finalists get labels and glide to their marks, the winner sinks to a target with pulsing rings. Returns frame.pick (screen point) so a card can open from it. |
| feature-beats | component | v2 | One feature per beat: big index number, brand icon chip, fitted title, one proof line. Slams in from alternating directions and clears before the next beat. Give each beat about 4 s. |
| funnel-counter | component | v2 | A big number that counts up to the starting pool, then drops through a mask to each smaller value while a two-line label slides and hugs its width. The last step can turn positive with a glow. Pairs with dot-field-scan. |
| hud-chip | component | v2 | A persistent pill (live dot, a value like a score, separator, uppercase meta) that wipes open from the left and keeps context on screen across scenes. Exposes `value` as a shared-element flight target (see scoreboard-flip flyTo). |
| logo-floor-drop * | component | v2 | End card: the brand logo falls onto the world floor as a real 3D decal, lands with a flash and sparks, then eyebrow, tagline, and CTA button spring in. Falls back to a wordmark when the brand has no logo file. |
| notification-drop | component | v2 | A phone-style notification (app icon, title, time, one-line body) that springs down from the top and flies back up on exit. Good for reactions, group chats, alerts, and social proof moments. |
| payoff-words | component | v2 | A centered display line that lands one word per beat (rise, scale, blur-in), optional accent words, clean exit. Give it a beat per word plus a 1.2 s hold. |
| ranked-climb | component | v2 | Optional two-line title over a ranked table. Your highlighted row jumps up slot by slot on beats while passed rows slide down; ranks and your record update; at the top the title's last word rolls to a new word and a trophy pops in. |
| rise-headline | component | v2 | Eyebrow plus 1-3 display lines; letters rise out of masks, the last line can slam on a beat, clean exit upward. Already mid-rise on frame 0. |
| scoreboard-flip * | component | v2 | Eyebrow, a big word over a rolling record ("DOWN / 2-4"), and a 3-column grid of metric tiles with W/L badges. mode 'enter' rises, slams, flips tiles up, glows swing tiles, then clears (the record can fly into a HUD). mode 'flip' smashes in, flips chosen tiles to a new state while the record rolls and callouts pop, then swaps the word ("DOWN" to "UP"). |
| word-montage | component | v2 | Rapid-fire display words, one per beat, with outlined echoes above and below and an optional mini card per word (built by a caller function). Entrances alternate zoom, right, left, up; each word exits toward the next entrance; the last word pushes into a hard cut. Give each word about 0.9 s or more. |
